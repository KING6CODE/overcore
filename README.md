
Tower Drive
===========

Tower Drive is a French-language browser tower-defense game, packaged for Android with a WebView.

## Play on the web

Open `index.html` in a modern browser.

## Android

The Android project is in `android/` and uses the Play Console application ID `com.king6code.towerdrive`.
Open that directory in Android Studio to build the app bundle. The release signing configuration reads the ignored local file `android/keystore.properties`.
